# Chatbot PDF QA Project

## Introduction
This project is a Streamlit-based chatbot application that allows users to upload PDF documents, ask questions about their content, and receive answers powered by large language models (LLMs). The system extracts text from uploaded PDFs, splits it into manageable chunks, creates embeddings for semantic search, and uses Groq's LLM API to generate answers based on relevant document context.

## Features
- Upload PDF files and extract their text
- Chunk and embed document text for efficient semantic search
- Query the document using natural language
- Get answers generated by Groq LLMs using relevant context from your documents

## Requirements
- Python 3.8+
- Internet connection (for API calls)

## Installation
1. **Clone the repository or copy the project files to your local machine.**

2. **Create a virtual environment (recommended):**
   ```cmd
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. **Install required libraries:**
   ```cmd
   pip install -r requirements.txt
   ```
   If `requirements.txt` is not present, install manually:
   ```cmd
   pip install streamlit PyPDF2 langchain openai faiss-cpu
   ```

4. **Set your Groq API key:**
   - The API key is set in the code as `GROQ_API_KEY`. Replace it with your own key if needed.

## Running the Project
1. **Start the Streamlit app:**
   ```cmd
   streamlit run chatbot.py
   ```

2. **Usage:**
   - Open the Streamlit web interface in your browser (usually at http://localhost:8501)
   - Upload a PDF file using the sidebar
   - Ask questions about the document in the provided input box
   - View answers generated by the LLM on the main screen

## Notes
- Ensure your API key is valid and the model specified in the code is supported by Groq.
- For large PDFs, embedding and search may take some time.
- If you encounter errors, check the Streamlit logs and ensure all dependencies are installed.
